Mis API Keys

Cada proveedor puede usar tu propia API key o la global del servidor. Si configuras una tuya, solo tú pagarás los consumos. Si la dejas vacía, se usa la global configurada en .env.

⚠️ Las keys se guardan cifradas con Fernet (AES-128-CBC + HMAC) en bases/auth.db. Nunca verás el valor completo después de guardarlas, solo enmascarado. Si la pierdes, vuelve a escribirla.
