# Argos OSINT — Guía rápida de identidad

Submarca de Soluciones Digitales en colaboración con Cuarto de Paz.
Plataforma de búsqueda OSINT/CLOSINT, mapeo de sujetos e investigación privada con IA.
Hermana de Themis IA: comparte navy, plata, tipografía y endoso; se distingue por el acento ámbar.

## Paleta
- Navy (fondo principal): #0B1026
- Plata (degradado vertical): #F2F3F5 → #9AA0AB
- Ámbar (acento, solo iris y "OSINT"): #E8B44A · sobre fondo claro: #B8801A
- Gris endoso: #7C8496
- Fondo claro: #F4F5F7 · Tinta para fondo claro: #2B3142 → #0F1425

## Tipografía
- Nombre: Michroma (Google Fonts, OFL), convertida a trazos. "OSINT" al 82% del tamaño de "ARGOS".
- Endoso y textos de apoyo: Inter Medium.

## Archivos
- vertical / horizontal / isotipo, cada uno en: oscuro, claro, mono-blanco, mono-negro (SVG + PNG)
- app-icon 1024 (esquinas redondeadas)
- favicon 64 SVG + PNG 32 y 180; versión simplificada sin nodos

## Reglas mínimas
- Área de respeto: mínimo la altura del iris ×2 alrededor del logo.
- El ámbar solo en iris y "OSINT". Nunca en el contorno del ojo, nodos ni "ARGOS".
- Por debajo de 140 px de ancho usar isotipo; por debajo de 48 px usar favicon (sin nodos).
- Sobre fotografía o fondos complejos, versión mono-blanco.
- Sistema de portafolio: cada submarca = navy + plata + un acento propio (Themis cian, Argos ámbar).
